# Fotos dos produtos

O site hoje usa emojis como placeholder no lugar das fotos (em `produtos-grid`, dentro de `index.html`). Quando tiver fotos reais:

1. Coloque os arquivos aqui, ex: `bolo-cenoura.jpg`, `cookies.jpg`.
2. No `index.html`, troque `<div class="produto-img">🍰</div>` por `<img src="assets/images/bolo-cenoura.jpg" alt="Bolo integral de cenoura">`.

**Recomendação técnica:** fotos quadradas, no mínimo 600x600px, formato `.jpg` ou `.webp`, cada uma com menos de 300KB (usar squoosh.app para comprimir sem perder qualidade visível).
