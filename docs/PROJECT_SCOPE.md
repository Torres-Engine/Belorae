# PROJECT_SCOPE.md

## Objetivo

Converter visitantes em encomendas via WhatsApp para a Belorae Confeitaria Saudável.

## Público

Pessoas buscando doces/confeitaria com apelo saudável (sem glúten quando possível, fit, etc. — **ajustar conforme o real posicionamento dos produtos**), encontradas via Instagram/indicação, que acessam o link pelo celular.

## Escopo — o que ESTÁ dentro

- Página única (one-page) com: apresentação da marca, destaques de produtos, prova social (opcional), seção de cardápio com 2 botões.
- Na seção Cardápio, 2 botões lado a lado: "Fazer Pedido" (abre o WhatsApp direto, com mensagem pronta) e "Ver Cardápio" (abre o PDF do cardápio). O PDF também tem, no próprio rodapé, um link de WhatsApp com mensagem pronta.
- Além dos botões da seção Cardápio, o site tem botões flutuantes fixos de WhatsApp e Instagram no canto inferior direito da tela, sempre visíveis durante a rolagem da página (não ficam mais dentro do rodapé).
- No total, o site tem 3 pontos de acesso ao WhatsApp: botão "Fazer Pedido" (seção Cardápio), botão flutuante fixo, e link dentro do PDF do cardápio.
- Cardápio em PDF disponível para download/visualização.
- Site 100% responsivo (funciona bem no celular — é onde a maioria vai acessar).

## Escopo — o que NÃO ESTÁ dentro (por enquanto)

- Carrinho de compras / checkout / pagamento online.
- Login de usuário, cadastro, área de cliente.
- Painel administrativo.
- Automação com API paga do WhatsApp Business.
- Múltiplas páginas (blog, sobre detalhado, etc.).

> Ver `docs/ROADMAP.md` para quando (e se) esses itens entram.

## Critério de sucesso

Visitante consegue, em até 2 cliques a partir do link do WhatsApp/Instagram, abrir uma conversa de pedido já com contexto (nome da loja + intenção de compra).

## Pendências de conteúdo (responsabilidade do dono do negócio)

- Confirmar nome oficial: "Belorae Confeitaria Saudável" (o nome enviado tinha um provável erro de digitação — "Saldável").
- Número de WhatsApp para pedidos.
- Lista de produtos + preços para o cardápio em PDF.
- Fotos dos produtos (mínimo 3–4 boas fotos).
